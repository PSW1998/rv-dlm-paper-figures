# rv-dlm-paper-figures

This repository contains the Python code and generated figures for the RV-DLM / RVL-DLM paper.

## Contents

- `RVDLMfigures.py`: all-in-one script used to download OHLC data, compute Rogers--Satchell realized variance, fit the SV-DLM, RV-DLM, and RVL-DLM models, and generate all paper figures.
- `RVDLMfigures/`: PDF figures generated by the script.
- `requirements.txt`: Python package dependencies.

## Data

The script downloads daily OHLC data from Yahoo Finance using `yfinance`.

The tickers are:

SPY, XLB, XLE, XLF, XLI, XLK, XLP, XLU, XLV, XLY.

## Reproducing the figures

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
